# CH00203：常量属性与对象协作

本节通过现有的 `A.m`、`Viewer.m` 和 `DataAcqusitionHardware.m`，观察常量属性与不同职责对象的基本结构。

## 先阅读哪些文件

- `A.m`：`properties (Constant)`，适合讨论类级别常量。
- `DataAcqusitionHardware.m`：用常量描述缓冲区大小；当前构造函数尚未实现真实硬件操作。
- `Viewer.m`：创建 Figure 和 edit 控件，是一个最小 GUI 句柄对象。

## 常量属性

```matlab
a = A();
A.R
```

`Constant` 属性由类定义给出，不能像普通对象属性一样在运行时随意改写。若常量表示单位换算系数，应使用有含义的名称和注释，说明单位与使用场景。

## Viewer 的最小实验

```matlab
v = Viewer();
```

运行后会创建一个 GUI 窗口。请在关闭窗口后检查对象生命周期和界面句柄的关系。该示例是旧式 `figure/uicontrol` 风格，适合用于理解对象封装；新项目也可以考虑 App Designer 或 `uifigure`。

## 建议的分层结构

```mermaid
flowchart LR
    UI[Viewer：界面显示] --> M[数据模型：数据与状态]
    M --> S[采集接口：统一读取方法]
    S --> HW[真实或模拟硬件]
    S --> TEST[模拟设备与自动化测试]
```

## 本节建议改进

1. 给 GUI 控件添加明确的布局、标签和关闭处理。
2. 使用私有属性保存内部句柄，公开只读状态或业务方法。
3. 把硬件读取行为定义为清晰接口，避免 Viewer 直接依赖具体设备类。
4. 通过模拟采集对象测试 UI 之外的数据处理逻辑。
5. 为缓冲区大小补充单位、取值依据和合法范围；不要把硬件参数仅作为无说明的数字常量。

## 练习

- 在 `A` 中增加静态换算方法，并说明它与常量属性的区别。
- 为 `Viewer` 增加 `setText` 方法，将控件访问封装在类内部。
- 设计一个模拟采集类，让它返回固定数组，验证数据处理逻辑无需真实硬件即可运行。
